# Worth the Wait?

A standalone purchase opportunity cost visual. Enter a purchase price and explore how that amount could grow under different annual return and time assumptions.

Open `index.html` in a browser. The project uses plain HTML, CSS, and JavaScript; it has no install or build step.

The projection assumes one investment today and applies the same annual return each year:

`projected value = purchase price × (1 + annual return) ^ years`

It is an illustration, not a forecast. Actual returns vary. Taxes, fees, inflation, resale value, and the personal value of the purchase are not included.
